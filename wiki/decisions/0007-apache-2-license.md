# 0007 Apache 2.0 license

## Context

The package depends on swift-openapi-runtime, swift-openapi-urlsession,
swift-openapi-async-http-client and swift-http-types, all Apache 2.0. Users
range from hobby apps to commercial servers.

## Decision

License the project under Apache 2.0 ([LICENSE](../../LICENSE)).

## Consequences

- Contributions are accepted under the same license (Apache 2.0 §5). No CLA.
- The OpenRouter name and logo are trademarks of OpenRouter, Inc. and aren't
  covered by this license. The banner uses the official, unmodified mark per
  https://openrouter.ai/brand, and the README states the project isn't
  affiliated with OpenRouter.
